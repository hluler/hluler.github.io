拾影 ClipDock · 网页视频保存

ClipDock for Chrome

由你主动扫描当前网页中的普通视频文件，勾选后批量保存到本机。

User-initiated detection and batch saving of ordinary video files from the current web page.

  • 支持普通 MP4 / WebM / MOV / M4V / OGV 文件及最多 100 条文件直链批量导入。
  • 最多 3 个并发任务，提供进度、取消、失败重试及本地记录管理。
  • 独立运行，无需安装桌面程序，无账号、广告、统计或开发者下载中转服务。
  • 不支持 YouTube、Google 视频来源、DRM、加密媒体、HLS/DASH 分段组装或音画分轨合并。

Only save content you own or have permission to save. This extension is not affiliated with the websites you visit. No guarantee of Chrome Web Store approval is made.

本工具只用于保存您拥有或获得授权的内容，与被访问的网站无隶属或官方合作关系。Windows 桌面版与 Chrome 版支持范围不同。
